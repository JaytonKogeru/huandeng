# v0.5 视觉与交互审计

审计基线：`8798d8f`，正式 v0.4 的源码与文档；重点反馈为 [Issue #6](https://github.com/JaytonKogeru/huandeng/issues/6)。本文件记录界面判断、已落地调整与实际验收边界。完整功能覆盖见 [AUDIT-V05-COVERAGE.md](AUDIT-V05-COVERAGE.md)。

## 结论

v0.4 的主要视觉问题是几个开发阶段的界面没有形成统一规则：桌面启动页为深绿，React 界面保留上游朱红，favicon 又是橙色幻灯片；项目编排几乎全英文，页面编辑则以中文为主；身份、顺序、文件路径都挤在相似的小字层级中。已有面板布局可继续使用，优先统一品牌、语言、选中状态和常用工具的行为。

下一版采用中性色工作区、白色内容面、深绿选择色与既有 H 标识。内容与画布保留主导地位。工具组、边界、字重和即时反馈承担层级。

| 欢迎页以大标语和斜叠纸片占据主要区域 | 左侧打开/新建，右侧最近项目；项目名、位置、打开日期分别排列 | 让日常恢复工作成为主操作 |

| `Project & Story`、`Save project` 等英文与中文页面面板混用 | 项目、演讲、故事、章节、版本、快速布局使用统一中文词表 | 降低理解和寻找操作的负担 |

| 新插入对象在图层中显示 `node-…` 长 ID | 有文本或自定义名称时保留；其余显示椭圆、线条、图片、图表等实际类型，ID 放在 tooltip | 用户能直接理解对象列表，永久标识仍可用于定位 |

界面实现集中在 `packages/core/src/app/styles.css`、`components/brand-mark.tsx`、`components/pptd` 下的 project / design-intent / recipe / page-history 面板，以及 `packages/desktop/welcome.*`。`scripts/sync-brand-assets.mjs` 和 `packages/desktop/brand-assets.json` 维护品牌资产。

插入工具选择、画布放置与缩略图性能由本轮编辑器实现负责，属于同一体验里程碑；这里的样式与这些操作的选中状态衔接。代码复核同时发现并推动修复了图形预览与最终轮廓不一致、菜单图标被默认尺寸压小、插入手势的多指与失焦取消、Shift 线条在边界处偏离约束方向，以及缩略图重排后当前页未跟随滚动等问题。

既有移动、缩放、旋转手势也补齐了同一取消规则：活动手势只接收发起指针的事件；第二指不能改选区或结束操作；失焦、失去捕获、Esc 和画布卸载恢复操作前的几何值。监听器先移除再释放捕获，避免释放触发的事件重复提交；取消后晚到的 pointerup 不写入文档。

## 动效约定

本次参考仓库中的 `emil-design-eng` 和 `review-animations` 设计规则，按实际操作频率选择反馈方式。

| 场景 | 实现 | 目的 |
| --- | --- | --- |
| 鼠标按压常用按钮 | 按下 70ms，释放 140ms，最多缩放到 0.97 | 立即确认输入；连续按压可中断 |
| 开始页主按钮 | 按下 70ms，释放 140ms，缩放到 0.98 | 保持相同反馈，适应更宽的按钮 |
| 下拉菜单、右键菜单、弹出层 | 进入 160ms，退出 90ms；从触发点展开 | 保持控件与菜单的空间关系 |
| 键盘焦点与快捷操作 | 按钮不位移；菜单获得键盘焦点时关闭过渡 | 高频操作立即响应 |
| 页面内容、删除、拖动、页面切换 | 未添加装饰动画 | 用户直接看到操作结果 |
| 减少动态效果偏好 | 取消按压位移和菜单缩放，保留短淡入；等待指示静止 | 保留状态信息并减少运动 |

没有增加动画依赖。新增运动仅使用 transform / opacity；工具数量、布局尺寸和画布几何不参与动画。
