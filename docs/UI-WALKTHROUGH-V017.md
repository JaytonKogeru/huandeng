# v0.17 界面与流程

| 工作区 | 主要工作 |
|---|---|
| 普通 | 编辑当前页对象、布局和动画 |
| 浏览 | 按章节查看缩略图、选择页面与调整主页面顺序 |
| 大纲 | 查看各页标题及 Story/内容摘要，检查叙事顺序 |
| 章节 | 设置章节起始页、名称与故事，对照成员预览保存草稿 |
| 备注页 | 对照当前页整理讲稿 |
| 历史 | 查看当前主页面的命名版本、操作记录及只读预览，显式恢复 |

从浏览选页 → 普通编辑 → 备注页整理讲稿 → 历史记录一个命名版本。浏览和大纲切换保留共同的筛选与章节折叠；不会替用户折叠左侧栏。章节快捷按钮和章节页签都进入同一个中央工作区。修改章节后先检查成员预览，再保存或放弃草稿。

历史不并入章节：章节管理页面的分组，历史管理一页随时间变化的内容。浏览卡片上保留查看历史入口，省去寻找菜单；历史工作区仍明确标出选中页面。固定版本引用显示主页面历史范围及只读提示。

未保存的结构草稿、输入法组合输入、版本保存或恢复会阻止会丢失上下文的切换。保存/恢复失败保留错误提示并释放忙碌状态，便于重试。
