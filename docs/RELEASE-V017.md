# HUANDENG Editor v0.17.0

普通、浏览、大纲、章节、备注页和历史成为同级工作区。浏览只展示缩略图，大纲直接展示标题与 Story/内容摘要，不再嵌套切换。左侧导航的展开状态、宽度和选中栏目保持独立。

章节管理从弹窗移入画布区域，复用同一份 Project 草稿。章节起始页、名称、前置内容和故事与成员页面预览在一起；保存和放弃仍然明确。已有入口跳到同一个章节工作区，移除章节不会移除页面。

历史成为当前页的独立工作区。浏览卡片、缩略图菜单和工具栏入口进入同一个位置。命名版本和操作记录仍然区分；预览未加载完成不可恢复，记录或恢复期间不可切换页面、演讲或工作区。固定版本引用可以查看对应主幻灯片历史，但保持只读。

本版不修改 PPTD 文档格式、不改变 Agent 写入协议，也不把大纲摘要替换成演讲备注。已有动画、Agent 修改审阅、可视化布局和放映入口继续保留。原始项目不参与写入验收。具体证据与交付状态见 [验收交付](HANDOFF-V017.md)。
