# 科研对象：使用方式、格式兼容与验收

本文件记录 v0.4 科研对象实现。完整产品要求仍以 [SPEC.md](SPEC.md) 为准；本文件不是替代规格。旧编辑器对照来自 THUG 上 `FreestyleScientificSlides/apps/pptd-desktop/vendor/open-pptd` 的实际 `editor/types`、`packages/model/chart`、`packages/renderer` 源码。

## 日常使用

工具栏 **科研对象** 可以直接插入表格、LaTeX 公式、Font Awesome 图标，以及 13 类图表。对象继续保存在原 `.page` 文件中，使用同一组移动、缩放、旋转、复制、图层、撤销、保存及命名页面版本工作流。

### 图表

选择图表后，在右侧修改标题、字体、字号、图例、数据标签、系列类型、数据列对应关系和系列颜色。柱状图、折线图、面积图可以混合系列；散点图、气泡图和雷达图支持各自的多个同类系列。环形图是饼图的内径设置。坐标图可以设置轴标题、范围、网格和横向布局。

数据编辑框接收 Excel 复制的 TSV，也接受 CSV。第一行是唯一列名，后续每行对应一条数据。支持引号内的分隔符、双引号和换行；`001` 这样的标识符保留前导零，数字测量值转为有限数值。空白单元格保持缺失值，折线不会跨空白补零。

**修改数据后点击“应用图表数据”。** 未应用文字是独立草稿，按项目中的页面和对象缓存；切页或切对象后可以继续编辑。应用时核对原始图表数据指纹，若外部 Agent 已改过同一份数据，保留草稿并提示冲突。“读取当前数据”明确放弃该草稿并读取当前对象。上层编辑器将未应用草稿纳入离开、关闭及导出的检查。

绘图复用 Apache ECharts 6.1.0 的 SVG 渲染器；图表模块按需加载。移动图表不重新计算绘图，改变数据或尺寸才生成新 SVG。所有数据都经过固定的类型适配器，PPTD 源文件不能提供可执行 JavaScript 回调。

### 表格

在右侧选择单元格，可以改文字、粗体、字号、填色和列宽，插入或删除行列，并指定矩形范围进行合并。表格使用原格式的压缩行：跨行、跨列覆盖的位置不占据新的数组项。编辑和导出都先恢复视觉网格，避免把第二个源数组项误当成第二个视觉列。

合并操作保留所有被合并单元格的文字，以换行连接，保留左上角的样式。拆分后组合文字留在左上角，其余格为空；这两个操作都可以撤销。插入经过已有合并范围的行列会扩展跨度；删除合并格原锚点时，内容移到剩余锚点。部分交叉已有合并格的选择会报错，要求包含整个格或先拆分。

表格复用共享的主题样式解析器，支持 `tableStyles`、`textStyles`、首末行列、循环 `bodyStyles`、`rowOverColumn`、单元格覆盖和四边独立边线。未定义的样式引用给出诊断。长文本可以撑高行；PPTX 导出使用实际渲染测量的行高。

### 公式

公式仍是普通文本对象的 `content.text`，支持 `\(...\)` 行内、`\[...\]` 和 `$$...$$` 块级 LaTeX。KaTeX 负责排版，浏览器显示 MathML；修改或重开不会把 LaTeX 源码替换成截图。表格单元格也使用同一文本渲染规则。

已有原始 `<math>...</math>` 内容可显示受支持的 MathML 结构，包括分式、根式、上下标、求和及矩阵。输入经过标签和属性限制，事件处理器和外部执行内容不能进入页面。LaTeX 解析错误保留表达式并显示错误。PPTX 对可转换的 LaTeX 写入 OMML；原始 MathML 及超出转换覆盖的构造使用明确报告的对象图像回退。

### 图标、图形和组合

图标使用本地 Font Awesome Free 7.3.1 的实心、常规及品牌集合，支持 `fas:name`、`far:name`、`fab:name` 和旧名称别名。按英文名称搜索并直接换图标，保留当前对象 ID 和位置。图标保持长宽比。编辑器提供 21 种常用几何形状；线条可设置实线、虚线、点线，以及箭头、凹尾、菱形、圆形端点。

选中多个对象后使用 **组合** 或 `Ctrl+G`，取消组合使用 `Ctrl+Shift+G`。组合是引用成员 ID 的透明外壳，成员仍位于同一页的 `elements` 数组里。移动、缩放、旋转作用于所有后代一次；复制会重建引用，取消组合保留成员的 ID 和绝对位置。旋转成员的非等比组合缩放会产生剪切，因此默认保持比例，对无法无损表达的变换明确报错。组合壳没有单独的透明度；需要调整具体成员。

## 图片导入

选择文件、拖入图片和粘贴图片共用同一导入 API。支持 PNG、JPEG、GIF、SVG、WebP，依据文件真实字节识别格式，忽略不可信的扩展名。单个文件上限 32 MiB。

PNG/GIF/JPEG 从图像头读取实际尺寸；JPEG 识别 EXIF 的转向，导入时保持显示方向的长宽比。WebP 读取 `VP8`、`VP8L` 和 `VP8X` 的实际宽高，不再使用固定 800×600。SVG 优先采用明确的宽高（含物理单位），必要时由 `viewBox` 推导缺失维度和比例。

导入保留原文件字节，以 SHA-256 命名存入 `media/imported/`。相同内容重复导入只保留一份；并发导入通过原子链接避免覆盖；同名哈希文件如果被用户改过，拒绝覆写并报告冲突。原始路径不会被作为写入目标。

SVG 导入限静态、自包含图形：可以引用文件内的渐变、裁切路径、符号，也可以内嵌 PNG/JPEG/GIF/WebP。脚本、事件、外部图片/CSS、DTD/实体定义、外部基路径、嵌入 HTML 和动态修改属性的动画被拒绝。该检查不重写图像。SVG 中通过外部字体或复杂 CSS 才能确定的布局不属于自动迁移保证；专业分析软件输出的自包含 SVG 或 PNG 可以保留为科研图像素材，但不会自动变成可编辑数据点。

## 与旧科研页面的格式对应

| 对象或字段 | v0.4 的实际处理 | 边界 |
| --- | --- | --- |
| `chart.data.cols/rows`、`series[].type/encode` | 支持 13 类基础绘制；保留数据、未知字段和对象 ID | 表必须矩形，列名唯一；最多 100 列、10,000 行、50 系列 |
| 旧 `category ↔ x`、`value ↔ y` | 双向别名，支持列名和数字列索引，包括第 0 列 | 不按显示位置重写源编码 |
| `seriesDefaults[type]`、`fill`、`lineColor` | 按类型继承，浅合并样式对象，使用官方颜色优先级 | 更细的旧图表样式不等同于像素级复刻 |
| 旧横条/横向瀑布 `x=数值/y=类别` | 由轴类型或数据推断，内部归一化后正确横向绘制 | 源文件编码保持不变；显式方向仍可调整 |
| 蜡烛图可选 `open` | 缺少 open 时使用 close 画出高/低/收盘范围 | 高低值必须包住开收盘值 |
| `scatter.dataFilter`、双轴、log/time 轴 | **明确诊断，停止该对象绘制/成功导出判定** | 不静默取消过滤、不把对数轴改为线性轴；当前用独立图表或已过滤源数据 |
| 雷达/树图/桑基等高级类型 | 可编辑源数据并在画布显示 | 部分高级对象在 PPTX 中是图像回退，不是可编辑 ChartEx |
| 精细数值格式、旧图表标签布局、趋势线、误差条、完整组合图约束 | 源字段保留 | 未完成旧模型所有属性的迁移；有这些要求时需对照实际页面逐项验证 |
| `group.children: string[]` | 兼容引用式组合，支持嵌套和整组旋转 | 堆叠顺序连续的成员导出为 PowerPoint 原生组合，支持嵌套；成员与其他对象交错时保留独立对象及原堆叠顺序，并在导出报告中说明 |
| `iconName` 三类前缀及旧别名 | 本地 SVG 路径，图标搜索与换色 | 当前实心颜色覆盖；旧渐变或定制外部图标库未完整迁移 |
| `table.rows`、`rowSpan/colSpan`、主题样式 | 合并网格、结构编辑、共享样式、原生 PPTX 表格 | 不等于完整 Excel；没有表格公式计算引擎 |
| LaTeX / MathML | 保留源表达式，使用成熟数学排版组件 | KaTeX 语法与 OMML 转换各有范围，错误/回退必须查看报告 |

这次适配补齐了旧编辑器缺失的主要对象类型，但“类型能用”与“所有旧页面样式完全兼容”是不同的验收项。现有实现不宣称覆盖 PowerPoint 的所有图表类型、SmartArt、母版、动画和嵌入对象。

## 可复核的验收

`science-objects.test.ts` 实际调用 ECharts SVG 引擎渲染 13 类图表，并检查数据不变、缺失值、非法数据诊断、旧编码/方向/样式、图标三类包、组合变换、表格结构编辑。`grouping-store.test.ts` 将组操作通过真实文档事务落盘，检查嵌套几何只变一次、页面/对象复制引用、删除/取消组合、撤销重做、未知字段及兄弟文件保持不变。`asset-import.test.ts` 使用真实编码的 PNG/GIF/JPEG/三种 WebP 和 SVG 测试尺寸、字节保持、去重、冲突与资源限制。

真实窗口的科学对象验收脚本：

```sh
node scripts/verify-science-v04.mjs
```

脚本新建独立临时工程，完整运行含 22 项检查：通过 GUI 插入 13 类图表、修改数据并重开、保留跨对象及跨页的无效 TSV 草稿、检测外部数据修改与草稿的冲突、编辑/合并/插入/拆分表格、LaTeX 和 MathML、三套图标集替换、组合移动/复制/取消组合/撤销，以及图片文件选择/拖放/粘贴、素材去重和重开。随后生成 PNG、PDF、PPTX，检查包内表格、chart 和 OMML，核对所有源页哈希未变。图表与图标首次使用检查页面没有额外重载；组快捷键前确认选择、焦点、保存和控件可用状态，不能把磁盘先写成功误当成客户端已完成。

证据写到 `.verification/science-v04/`，包括各图表截图、`image-import.json`、`imported-image.png`、导出文件、导出报告和 `result.json`。只有 `passed: true` 的完整运行才能作为通过记录。`HUANDENG_SCIENCE_NO_EXPORT=1` 只用于单独诊断 UI，不能替代完整导出验收；`HUANDENG_BROWSER` 可以指定实际 Chromium/Edge。

## 采用的组件和依据

- [Apache ECharts SVG SSR](https://echarts.apache.org/handbook/en/how-to/cross-platform/server/)：复用图形引擎，应用维护受控的 PPTD 数据适配。
- [Font Awesome Free 许可](https://fontawesome.com/license/free)：图标由 Fonticons, Inc. 提供，SVG/JS 图形使用 CC BY 4.0，其他代码为 MIT；发行包保留说明。
- [KaTeX 选项与安全边界](https://katex.org/docs/options.html)：数学排版继续复用 KaTeX。
- [WebP 容器规范](https://developers.google.com/speed/webp/docs/riff_container)：图像尺寸来自对应位流/容器头。
- [SVG 坐标与固有尺寸](https://www.w3.org/TR/SVG/coords.html)：明确宽高与 `viewBox` 的优先关系。

导出适配的详细支持范围以导出报告及 PowerPoint 差异审计为准。
