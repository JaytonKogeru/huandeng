# HUANDENG v0.8 实施记录

依据 [Audit](AUDIT-V08.md) 与 [Spec](SPEC-V08.md)，本轮以点击驱动的现场放映为主。下列记录实现，实际交付回执另见Validation。

## 模型与共用文档服务

schema2 effects为唯一保存源，纯编译为既有v1轨道。六种效果：出现、淡入、淡出、消失、强调、相对移动；三种触发：单击、同时、接续。首效果ID标识点击组，组末为停点；未来动作保持前态，进入初态隐藏，强调恢复基础比例。叶子opacity与已烘焙组opacity遵循既有显示语义。

build-model.ts验证和编译，animation-model.ts提供union/resolver，采样沿已有矩阵与组继承。单轨上限提高到1024以支持256个强调动作；4096轨、50000总帧、10分钟边界保留。

page.timeline.set沿同一CAS/journal/requestId/Undo。删除按原click组清理，组内首剩余项提升为click；复制/粘贴保留作者模型及身份映射；非空v1/v2混合粘贴拒绝，不丢动画。版本、重复引用、重开均用同一数据。未来schema禁止当前writer覆盖。

page.transition.set独立保存无/淡化，v1/v2/无对象动画页面同样可用。静态与视频报告明确TRANSITION_NOT_EXPORTED，本轮无原生PPTX动画映射。

## 作者与放映界面

AnimationPanel分流默认步骤和旧高级时间线。BuildPanel提供对象/效果、组重排、触发/时长/延迟/位移、逐步预演、草稿复制及冲突处理。多选默认同次点击。显式转换一次写派生v1，Undo回v2，不维护两套权威数据。

预演和放映共用usePresentationPlayback。播放中前进完成本组，全部完成才换页；后退回停点，跨页回末态。按page/occurrence/version隔离，首render采样目标初态，暂停/换源/卸载取消RAF。

画面点击、Enter/Space/方向键/PageUp/PageDown均可推进；忽略按键自动重复。全屏、黑屏暂停/恢复、闲置隐藏控制、可展开时间滑杆、同窗口备注。页面淡化只改显示层，减少动效偏好时省略转场，主动播放的对象动效保留。

## 审核与集成修正

首轮真实源码运行通过11组放映和16组作者交互。root复看1040×680截图，发现预演时编辑控件仍占294px、画布仅268×151，因此要求预演隐藏创作参数并重新验画布尺寸；不能仅凭用例通过接受视觉结果。

预演改版后同一16组实机通过；1040×680预演面板103.656px、画布606.833×341.344px。root亲自复看合成截图接受，返回编辑保留未确认输入。

独立复审发现全屏F1的body Portal以及黑屏展开时间条的播放入口。修正为全屏帮助先退出全屏再打开并暂停动画，黑屏禁用播放/seek；画面、按钮、键盘统一读取同步导航门闩。增加对应实际用例。顶部重新开始放映也清除上次回退的末态记录；键盘和按钮启动保持一致。旧键盘回归抓到Home→End连续绝对定位被导航门闩吞掉；绝对定位现在替换在途请求，相对推进仍等待页面切换提交，避免作用在旧页。

删除中间效果的复审发现仅过滤数组会改变with/after的前项，导致原本相隔的淡入/淡出重叠。修正规格为保留原组局部调度时间，再重建触发/延迟；首项提升click保留原等待，删尾缩短组末。针对对象删除、效果删除与筛选复制分别验证。

## 性能判断

raw-CDP对照把Network inspector独立为变量，同进程解除保留实验确认此前驻留曲线受调试网络响应显著影响；native dump验证操作场景低水位趋稳。产品没有加入强制GC或清缓存。完整快照解析、SSE慢消费者背压保留为后续有测量依据的任务。
