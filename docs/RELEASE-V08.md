# HUANDENG Editor v0.8 — 点击驱动的现场放映

本轮按 [审计](AUDIT-V08.md) → [规格](SPEC-V08.md) → [实施](IMPLEMENTATION-V08.md) → [验证](VALIDATION-V08.md) 推进。v0.8 把对象动画的主入口改成演讲步骤：演讲者决定何时继续，步骤内部决定对象如何出现、移动、强调或退出。

**v0.8.0 已完成正式安装和原项目重开。** 干净运行时 `ecba4cb`，最终 EXE **131/131**、25 轮放映、80 页副本 50 对编辑及安装 smoke 均通过。共 29,160 个包文件逐一匹配 SHA-256 和大小；旧版保留，原件 82 个文件与本轮基线一致。版本标识 `editor-v0.8.0`，完整来源和交付边界见验证报告。

## 可以怎样使用

选中图片、文字、图形或组合，打开「动画」，为对象添加出现、淡入、强调、移动、淡出或消失。选择「单击时」「与上一项同时」「上一项之后」，设置时长和延迟，就可以编排一次点击中发生的事情。多个选中对象默认同次播放。

例如一页结果图可以这样安排：开场只显示标题；第一次点击展示 Figure A；第二次点击出现箭头并强调重点；第三次点击展示 Figure B，同时淡出旧说明；最后一次点击进入下一页。无需先创建透明度轨道、手工填起终值，再另建时间线停点。

「逐步预演」使用与正式放映相同的规则，返回编辑恢复基础排版。旧的自由关键帧时间线继续保留；新步骤可以明确转换到高级时间线，转换可撤销，旧文档不会被自动改写。

## 现场演讲行为

| 操作 | 行为 |
| --- | --- |
| F5 / Shift+F5 | 从序列开头 / 当前页重新开始放映 |
| 点击幻灯片、Enter、空格、右/下、PageDown | 播放下一步；正在播放时完成当前步；本页完成后才换页 |
| 左/上、PageUp | 后退到前一步；开场再后退到上一页的完成状态 |
| Home / End | 定位首尾，覆盖尚未完成的绝对定位请求 |
| B / 句点 | 黑屏并暂停；恢复画面时不消耗下一步 |
| F / Esc / F1 | 全屏 / 退出 / 键盘帮助 |

重复使用的页面每次出现都从开场开始；固定版本播放该版本的对象和动画。按钮和输入框保留原生键盘行为，长按不会连续跳过步骤。放映控制闲置后隐藏；备注与下一页按需展开。

每页可设置无转场或淡化进入。页面转场、对象动画和基础排版分别处理，播放不会逐帧保存，也不会污染 Undo 历史。

## 工作台与数据保障

预演时自动收起作者参数和换页设置，给画布留出空间；返回后恢复选择、展开状态和输入。在 1040×680 的真实候选窗口中，预演画布为 606.833×341.344 px。基础属性与动画参数同时展开时仍显拥挤，已记为下一轮需要整合的创作界面问题。

点击步骤使用一份 schema 2 作者数据，播放时纯计算到已有采样器；不会保存两份独立可编辑动画。对象删除、复制、组、撤销、命名版本和外部冲突继续走同一文档事务。删除中间效果或部分复制时，保留下来的效果维持原点击组里的等待和并发关系。

## 性能结论的修正

本轮确认，先前 v0.7 的 renderer 增长曲线明显受到网络检查器保留响应影响。同一进程关闭 Network 并再次 GC 后，working set 从 371.10 MiB 回到 217.55 MiB，接近无 Network 对照 GC 后的 219.95 MiB；JS used 与 DOM/listener 没有相应变化。

因此，不能继续把旧 GC 后约 398 MiB 当成已证明的日常编辑泄漏。本轮没有靠定时 GC、清缓存、缩减 Undo 或降低原图质量改变指标。最终 v0.8 已通过 25 轮连续放映和 80 页副本的 50 对编辑：逐轮退出后 RAF 与放映 DOM 清零，1051 个受观察节点最终全部可回收；编辑场景 renderer 在自然空闲后约 223 MiB，Delete 视觉中位 24.75 ms。完整观测及限制见 [Validation](VALIDATION-V08.md)；有限场景通过不代表数小时混合高清素材使用已经验收。

## 保留能力与边界

已有 MP4 输出保留并做兼容回归。PNG / PDF / PPTX 仍输出基础静态画面，尚不包含 PowerPoint 原生点击动画；MP4 仍为静音定时输出，不包含页面转场。GIF 等素材仍自主播放，没有与演讲步骤统一的音视频时钟。
