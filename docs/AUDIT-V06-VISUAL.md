# HUANDENG v0.6 — 工作台视觉与操作审计

日期：2026-11-08（Australia/Sydney）。基线为已验收 v0.5，见 [既有视觉审计](AUDIT-V05-VISUAL.md)；本轮设计与 [SPEC-V06](SPEC-V06.md) 一起执行。

## 判断依据

v0.5 的中性工作区、深绿选择色、细边界、工具分组和 H 标识已形成一致外观。v0.6 应继续让文稿成为视觉中心，通过工作区收起、清楚的当前状态和精确导航减少操作负担。增加时间线、项目关系和素材库时，需要控制面板密度与画布面积。

已读取用户授权的 m6A 原始 PPTX 结构，并在隔离副本上通过真实 PowerPoint 只读打开、无修复导出全部 57 页。原文件摘要不变。已直接查看第 1–8、25–32 页接触表：大量页面采用白底、简洁标题、原图与证据并排，章节过渡使用深色整页；复杂比较、表格和分子图形主要依靠对齐和留白建立关系。这些样式支持工具采用安静、紧凑的工作台，保留作者对画面结构的控制。此处是视觉需求分析，不代表已实现 PPTX 导入。
