# v0.9 智能排列实现交接

日期：2026-11-08。执行依据为负责人批准的 SPEC-V09 §2。此记录覆盖实现和纯规则验证；真实桌面、保存重开、偏好持久化及安装结论由总 Validation 记录。

## 已实现

- `app/lib/inspector/geometry.ts`：保留旧 `snapMove` 接口；新增 `rotatedRect`、冻结引用的 `createSnapTargets`、`snapMoveWithSpacing` 和 `snapResize`。最近参考与同距取舍保持确定性；直接边/中心和等距同时命中时优先直接对齐。
- `app/lib/pptd-geometry.ts`：`rootSelectedElements`、`elementVisualRect`、`snapTargetsForSelection`、`arrangeElementBounds`、`distributeElementBounds`。移动组排除全部后代；单独编辑组成员时排除祖先，保留无关兄弟；其他组作为完整参考对象。原 bounds 数字数组与引用冻结值分离。
- `editor-canvas.tsx`：`snapEnabled` 默认 true；鼠标拖动在手势开始冻结参考，使用旋转后的 AABB 求统一位移；Shift 禁止另一轴修正或导线；Alt 暂停全部吸附。未旋转 resize 只匹配活动边或角，保持反向锚点、8单位下限、组/Shift 等比例；旋转 resize 维持既有行为。
- 组与普通多选移动都按根选区执行。Shift 按住后拖动已选对象不会先取消选区；无移动释放才执行原本的 Shift 单击取消选择。Esc 取消仍走原 `onCancel`，无新增后台写入。
- 新 `ArrangementControls` 提供选区/页面参照、六向对齐、横纵均匀分布；`SnappingToggle` 为受控开关。按钮、aria、画布键盘说明和富文本工具共用 `useHuandengLocale`。专属字典 `locale/huandeng-arrangement-messages.ts`，不翻译用户正文或对象名。
- 等距指示为两段测量线、端点与数字；线宽、端点和字体随 scale 换算，保持屏幕尺寸，只在实际命中时显示。结束、取消、切换页面随既有手势销毁。

本轮没有新依赖，没有复制第三方工程代码。复用原 `distributeRects`、`resizeRect`、pointer capture、group transform 和共享事务。路由、Inspector 接入和桌面偏好由主代理/i18n 代理负责，本子任务未改这些文件。

## 实现边界

等距支持把选区放在两对象之间、延续已有空隙；要求正交范围相交、间隙为正、不被中间对象占据，且建议位置不会撞入其他参考对象。页面外框仅参与边/中心吸附，不形成页面边缘的等距候选。完全在页外的对象不作为参考。尚未实现手工标尺/网格、锁定隐藏、旋转 resize 吸附。

每轴最多进行100,000次相邻候选与遮挡检查，避免高密度页面在开始拖动时进行无界配对；达到预算后保留已找到的间距，所有对象的边/中心参考仍在。普通页面的间距会完整处理。这里的限制只约束临时编辑辅助，不限制文稿对象、精确数值、平均分布或保存。

锁比例角点的吸附也必须在两个活动轴的屏幕阈值内，避免细长对象为横向1像素吸附而在纵向突然跳数百像素。

## 建议桌面验收几何

文档单位，页面1280×720。不同场景建议分开页，防止其他对象干扰参考。鼠标位移乘当前画布scale，勿把屏幕坐标当成文档单位。

| 场景 | 初始几何 | 动作 / 预期 |
| --- | --- | --- |
| 两侧等距 | 左图 `[100,50,40,40]`，右图 `[300,50,60,40]`，移动文本 `[0,50,80,40]` | 文本 raw x=177 → x=180；两个 gap 数字均40。Alt 同样拖动停177且无导线；关闭吸附也停177 |
| 延续间距 | 左图 `[100,50,40,40]`，右图 `[200,50,60,40]`，移动文本 `[0,50,80,40]` | raw x=317 → x=320；原/新 gap 均60 |
| Shift 入口和轴锁 | 选中 `[100,100,100,40]`；参考 `[600,103,100,40]` | Shift 在按鼠标前已按住，向右50 → `[150,100,100,40]`，y不能变103。Shift无移动单击仍可取消选中 |
| 旋转外沿 | 当前 `[100,100,100,40]`、rotation90；参考 `[200,350,80,80]` | 向右 raw27 → delta30，原 bounds x130；可见右边应在200，宽高/rotation不变 |
| resize | 当前 `[100,100,100,50]`；参考 `[250,175,60,80]` | e边向右47 → 宽150、高50、左边100；se角位移47,22 → `[100,100,150,75]`；Shift等比保持2:1 |
| 组自吸附 | a `[100,100,40,20]`，b `[180,100,40,20]`，组 `[100,100,120,20]`；无临近其他对象 | 选组向右3、向下30必须实际移动，不能被自己的成员吸回；Esc恢复全部组成员；Undo恢复一次手势 |
| 平均间隙 | a `[0,100,40,20]`，b `[80,100,60,20]`，c `[300,100,80,20]` | 水平均匀分布后 x为0、140、300，空隙100、100；两端不动；一次Undo复原 |
