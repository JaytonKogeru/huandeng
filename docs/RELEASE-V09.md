# HUANDENG Editor v0.9 — 中英文编辑、智能排列与 Story Plugin

日期：2026-11-08。

v0.9 完善日常编辑的三条工作流：在中文和英文之间切换界面；更可靠地移动、对齐和分布对象；让外部 Agent 围绕 Story 提出可检查、可保存、可撤销的修改。既有点击驱动的动画编排与现场放映继续保留。

本轮依据 [Audit](AUDIT-V09.md) → [Spec](SPEC-V09.md) → [Implementation](IMPLEMENTATION-V09.md) 推进。最终安装包来源、实际安装与重开结果、GitHub 同步状态，以最终 [Validation](VALIDATION-V09.md) 和 [Handoff](HANDOFF-V09.md) 的交付记录为准。

## 1. 中文与英文界面

可在编辑器顶栏、桌面原生菜单和欢迎页选择 **English / 简体中文**。语言覆盖编辑器主面板、属性与科学对象、项目和 Story、素材库、历史版本、动画、预演、放映、导出、帮助及桌面入口。

- 桌面端保存语言偏好，重新打开项目后继续使用；首次启动按系统语言选择。浏览器模式使用自己的偏好。
- 切换语言保留当前选区、输入草稿和 Undo 状态，保持当前文档打开。
- 已有标题、正文、Story、备注、对象名和动画步骤名属于文稿内容，保持原文。新建对象的默认文字按创建时语言生成。
- 日期、数量、按钮提示和无障碍标签随界面语言显示；未识别的外部错误保留原始细节。

英文侧栏导航改为等宽文字标签，保持顶栏和导航的单行布局。“连接 Agent”弹窗也调整了宽高边界，便于在较小窗口中访问和复制配置。

## 2. 智能辅助线、对齐与均匀分布

画布提供可见的吸附开关，默认开启，并将选择保存为编辑器偏好。移动图片、文字、图形和组合时，可以对齐页面或其他对象的边缘与中心，也可以把对象放在两项之间保持相同间距，或延续已有间隔。

辅助线显示等距端点和距离，缩放画布后仍按屏幕距离判断吸附。旋转对象按其可见外框参与移动和排列；组合按整体处理，修复了被自身成员吸回的问题。按住 Shift 再开始拖动已选对象时，选区继续保留，吸附也不会改动被锁定的另一方向。

属性面板可以明确选择 **所选对象 / 幻灯片** 作为对齐参照，并使用左、中、右、上、中、下六向对齐。选中至少三个对象或组合后，可使用水平或垂直均匀分布：两端保持位置，中间对象按相等空隙排列。

未旋转对象的缩放增加了边、角吸附，并保留固定对边、最小尺寸与比例约束。每次拖动或排列仍通过一次文稿操作保存，可用一次 Undo 撤回。

### 常用操作

以下按键在对应画布或手势中生效；文字、表格和属性输入框保留自己的键盘行为。

| 操作 | 行为 |
| --- | --- |
| Alt + 拖动 / 缩放 | 本次手势临时关闭吸附 |
| Shift + 拖动 | 限制移动方向，吸附保持轴锁 |
| Esc（拖动或缩放中） | 取消当前手势并恢复原位置 |
| 方向键 / Shift + 方向键 | 移动 1 / 10 个文档单位 |
| Tab / Shift + Tab | 选择下一个 / 上一个顶层对象 |
| Ctrl + Z / Ctrl + Shift + Z 或 Ctrl + Y | 撤销 / 重做 |
| Ctrl + G / Ctrl + Shift + G | 组合 / 取消组合 |
| F6 / Shift + F6 | 在编辑区域之间切换焦点 |
| F1 | 打开完整键盘帮助 |

方向键、Tab、组合和焦点切换沿用已有编辑能力；本轮重点补齐排列入口和手势可靠性。更多实现边界见 [排列专项记录](notes/V09-SNAPPING-IMPLEMENTATION.md)。

## 3. 连接 Agent，按 Story 预览与实施修改

从项目面板或桌面原生菜单打开 **连接 Agent / Connect an Agent**，为当前项目生成 Codex、Claude Code、DeepSeek Harness 或 ChatGPT 工作站通道的配置。复制后按目标客户端的方式加载；配置生成不会覆盖其他客户端设置，也不会被显示为已经连接成功。

桌面交付布局包含 Plugin 和运行所需脚本，配置使用当前 HUANDENG 安装内的运行时。桌面生成的连接使用应用自身的 Electron Node 模式，无需另装 Node。连接诊断会检查实际服务、工具和目标项目，避免连接到另一个文稿。

共用的 **huandeng-story** skill 支持以下流程：

1. 读取主 Story、章节、演讲及页面上下文，确认受众、问题、已有证据和希望传达的结论。
2. 形成具体的页面、对象、备注和点击讲解计划，保留原图、科学数值及作者指定的约束。
3. 预览将改变哪些字段、文件和页面，以及共享页面的复用影响。预览不会保存文稿或生成历史记录；大型结果会明确提示截断，新页的正式身份以提交结果为准。
4. 沿用当前任务的授权应用修改；仅要求审阅的任务停在提案。应用时核对预览对应的完整内容，并检查页面版本，防止覆盖中途的人工作业。
5. 读取保存结果、渲染页面，并在编辑器中检查实际点击放映效果。重要阶段可再记录命名版本。

Main 页仍是共享内容，occurrence 表示演讲中的一次使用，位置由编排计算。修改 Main 内容会影响实时引用，固定版本保留归档画面；演讲专属备注继续保存在对应实例中。Story 的 Agent 解释记录不代表作者审批。

开发接口新增 `huandeng_preview`、CLI `preview` 和可绑定 `previewHash` 的 apply，复用编辑器的同一个 writer、冲突检查、幂等重试、保存及 Undo。MCP 现在提供 18 个工具和两个 Story/operations 指南资源。连接和操作方法见 [Plugin 使用说明](../plugins/huandeng/README.md)。

## 4. 继续保留的能力与当前边界

已有原位 PPTD 编辑、独立页面身份、保存和 Undo、命名历史、素材库、Section / Presentation 复用、点击动画、逐步预演与现场回退继续使用。界面语言和吸附偏好不写进文稿，已有 CLI / MCP apply 调用保持兼容。

目前仍有以下明确缺口：

- **排版与创作空间：** 面板密度和可调工作区仍需改进；锁定/隐藏、精细图层操作、交互裁剪、完整段落排版，以及标尺、手工参考线和网格工作流尚未补齐。旋转对象的 resize 本轮仍不提供新吸附。
- **真实演讲工作流：** 当前备注/下一页仍是同窗辅助。独立双屏演讲者视图、计时和彩排，以及与点击步骤统一控制的音视频播放尚未完成。
- **复用与交付：** 演讲实例的局部视觉变体仍待实现。PPTX / PDF / PNG 继续输出基础静态画面，尚不携带 PowerPoint 原生点击动画。已有静音定时 MP4 输出保留。
- **长时间性能：** 数小时混合高清素材编辑、增量回读和事件背压仍需专项。v0.8 已修正旧内存测量受到网络检查器影响的结论；本轮没有新的长会话泄漏修复或完整压力验收声明。

评论、科学组件注册、高级统计图、母版与布局继承、完整 PPTX 导入往返和云端协作也仍在后续范围内。与 PowerPoint 必要功能的具体对照见 [本轮审计](AUDIT-V09.md)。

## 5. 下一阶段顺序

优先改善创作工作区和必要对象操作：可调面板、锁定/隐藏、图层、交互裁剪与文字段落。随后推进独立演讲者工作区、计时和彩排，再补受控媒体和演讲实例的视觉变体。

原生 PPTX 动画从可清楚映射的效果子集开始，并以实际 Office 放映作为验收条件。Plugin 在已完成的 DSH 闭环上继续补 Codex / Claude 的真实任务；长会话与高清素材性能按具体负载并行调查。下一轮继续按 Audit → Spec → Implementation → Validation 组织，功能范围和未完成项保持可追踪。
