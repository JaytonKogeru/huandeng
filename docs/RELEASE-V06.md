## 2. 日常编辑和键盘

画布成为一个稳定的键盘工作区。Tab / Shift+Tab 遍历顶层对象，组合只停靠一次；方向键移动 1 单位，Shift 10 单位；Enter 进入文字，Esc 返回或取消当前手势。F6 / Shift+F6 移动工作区，F1 打开快捷键帮助。缩略图有统一活动入口，支持方向键、Home/End 和准确的重复引用导航。

文字、数值、表格、弹窗和菜单继续使用自身键盘语义。只读页面仍能浏览，保存中不会把浏览操作当写入一并阻断。实际移动/缩放后按 Esc 再松鼠标，不产生新事务，也不改变文件字节。

这次真实验收发现并修复了三个操作问题：聚焦画布动态修改 tabindex 带来的 44–46 ms 开销、快速 Home → Enter → PageDown 的旧路由状态，以及动画预览误显示文档只读。修复前的失败记录保留，没有用测试延时掩盖导航问题。

## 3. 一个项目中的主库、章节与多场演讲

Main Slides 继续是同一项目的主页面库，Presentation 保存页面或章节引用。新概览展示衍生演讲；当前页的使用位置可以直接进入准确的那一次出现，不需要复制两套 PPTD 才能组织不同演讲。

以同一目录页在第 3、16、32、56 页出现为例：页面 `pageId`/短码不变，四次引用各自有 occurrence 身份，position 根据当前顺序计算。修改 Main 会更新所有 live 引用；固定版本保留已记录内容。显式单页引用支持各自的讲稿和版本，整章动态引用先“拆为独立页面引用”再逐页配置。

每次出现的任意视觉覆盖没有加入本轮。需要不同章节高亮时，先使用明确的页面变体或版本，避免一个看似相同的页面暗中保存多套内容。

## 4. 素材、字体与页面范围

素材标签提供原文件名搜索、图片预览、使用位置、对象定位、导入和复用。复用引用现有资源，不复制一份新字节。缺失或不可用的图片可重新选择文件修复，保持位置、大小、裁切、旋转和其他对象；并发修改仍按 revision 检查，冲突不会静默覆盖。

文字编辑不再让整页图片都取得新的 URL；素材自身变化才更新对应资源身份。图表 SVG 缓存保留 32 项上限并增加约 8 MiB 的字符串预算和 LRU 淘汰。它是有针对性的资源改进，不代表长期内存问题已经解决。

技术检查按实际本机枚举、已加载字体与有效字体栈报告可用、回退或未核实；按当前渲染测量文字、公式和表格局部范围，支持定位对象与检查过期提醒。检查不自动缩字或重排，也不声称验证了逐字形覆盖或 Office 的最终排版。

## 5. 可编辑关键帧与演讲步骤

时间线保存在 `.page` 的版本化 `timeline` 中。支持位置 x/y、旋转、水平/垂直缩放和不透明度，多轨关键帧增删、时间与数值修改、水平拖动，以及 linear / ease-in-out / hold 三种插值。

新增轨道带有采用基础值的首尾关键帧；修改结束值即可做出第一条运动。播放头可定位、播放和暂停；添加 cue 后，放映按演讲步骤前进/后退，重复 occurrence 从起点重新播放。预览只采样动画，不逐帧写回基础几何；点击“返回编辑”继续基础排版。

保存、Undo/Redo、对象复制重映射、删除清理轨道、命名版本、冲突草稿和原请求恢复使用同一文档机制。未知未来 schema 保留，时间线草稿在源页被删或外部换版本时仍能复制出来。实际 15 组动画验收包含拖动、取消、正常重开、固定版本、cue、深色和 reduced-motion。

当前 PNG/PDF/PPTX 输出基础版式，三种报告均标记 `renderState: 'base'`，有时间线时说明 `TIMELINE_STATIC_EXPORT`。视频编码、指定时间帧输出、运动路径/曲线、自动打关键帧、音视频/GIF 同步和 PowerPoint 原生动画还没有完成。详细操作见 [ANIMATION](ANIMATION.md)。

## 6. Story 与 Plugin

本机 CLI/MCP 继续连接同一个打开项目和 writer，共 15 个工具。新增 briefing、presentation read 和 assets list。Agent 先读取 selection，再按页面/演讲/occurrence 取得四层 Story、前后页、备注、版本和素材上下文，然后携带当前 revision 与 requestId 修改文档。

本机 stdio launcher 在包含空格的路径下完成 SDK 初始化、列工具及实际调用等 9 组检查。提供 Claude Code 包装和 Codex MCP 配置，已有网页 ChatGPT/WALT 也可调用相同 CLI。桌面安装不会自动将插件装入用户客户端；具体 Codex/Claude 客户端、私有 ChatGPT 连接和插件市场发行需要独立验收。

Story 是可维护的叙事资料，不自动补全科研证据或保证整场论证正确。下一步可在这些稳定上下文上建立可查看、可逐项应用的编排建议。接口和客户端差异见 [Plugin 指南](../plugins/huandeng/README.md)。

## 7. 视觉与实际验收

工作台沿用中性背景、深绿选择色、细边界和清楚的工具分组。左右面板可收起，素材库和时间线按工作任务展开；按钮按压与菜单使用既有短促反馈并尊重 reduced-motion。没有为排版对象的几何修改加入拖慢操作的装饰过渡。

用户的 m6A 57 页 PPTX 在隔离副本上通过实际 PowerPoint 只读打开和全页导出，原文件未变。视觉审计参考其白底证据页、深色章节页、图像比较和留白；这次查看不表示编辑器已经支持 PPTX 导入。可提交的实际合成截图为 [素材库](evidence/ui-v06/asset-library.png) 和 [时间线](evidence/ui-v06/animation-timeline.png)。
