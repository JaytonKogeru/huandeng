# HUANDENG v0.5 — 日常编辑体验

本版从 [综合产品审计](AUDIT-V05-COVERAGE.md) 和 [Issue #6](https://github.com/JaytonKogeru/huandeng/issues/6) 出发，合并初始 SPEC 与 v0.2–v0.4 的产品决定。目标是让现有科研编辑、主库/演讲、故事、页面版本与导出成为可持续使用的日常工具。

## 1. 本版交付

### 大项目流畅度

- 缩略图保留完整页面导航，只为可视区域及邻近页面挂载昂贵的页面渲染器；页面跳转、搜索、重排、固定版本及重复引用继续使用稳定身份。
- 快照复用未变化页面、主题和元数据；同一草稿复用投影；并发刷新合并。
- 新增和删除对象先更新本地画面，保存状态仍等待真实事务确认。确定失败恢复画面；结果未知时保留同一请求与重试状态。
- 文档读取采用有界并发；源文件内容仍真实读回，未变内容复用解析结果；共享素材指纹每轮去重。
- 保留 CAS、幂等请求、journal、恢复、第三方修改检测和内容读回。计时分别报告视觉反馈与持久化完成。
- 正式桌面预构建独立编辑器前端，由本机静态宿主复用同一份文档 API；打开项目不再即时编译前端。开发模式保留 Vite。
- 正式桌面的启动路径单独测量；根据证据优化界面加载及运行内存。

### 常规插入与键盘

- 文字、形状、线条先选工具，再在画布点击或拖拽放置；形状选择显示全部现有种类。
- 点击使用合理默认尺寸，拖拽指定尺寸；反向拖拽、缩放后的坐标、页面边缘均需正确。
- Shift 约束形状比例与线条方向；Esc 取消；插入完成回到选择工具。
- 文字放置后进入编辑；中文输入、文本删除与对象 Delete/Backspace 区分。
- V/T/R/L 分别选择、文字、矩形和线条。快捷键只在非文字输入状态生效。
- 图片导入、拖入、剪贴板和 SVG 工作流保留；表格/公式/图标归入“数据”，13 类图表放入子菜单。

### 身份与信息架构

- 页序显示当前位置；四位随机短码显示页面身份。原 UUID、S 别名与历史/演讲引用均保持有效。
- 缩略图右键提供复制短码；搜索兼容短码、旧编号与标题。
- 中文主标签统一为：主幻灯片、演讲幻灯片、项目与故事、主故事、章节故事、演讲故事、幻灯故事、快速布局。
- Main Slides / Presentation Slides 等英文模型名称可作为说明，协议与持久化字段保持兼容。

### 视觉与反馈

- 以现有桌面深绿色 H 标识为统一品牌源，派生桌面 PNG/ICO、favicon 和界面标识。
- 中性色工作区、清楚的工具分组、适合中英混排的字体、可读的选中/焦点/保存状态。
- 开始页优先显示打开、新建和最近项目。
- 按钮按压、悬停与菜单使用短过渡；尊重减少动态效果设置；画布输入不等待动画。

## 2. 验收

| 范围 | 必须证明 |
| --- | --- |
| 数据正确性 | 过期事务仍拒绝；未知结果使用同 requestId；发送中输入、撤销和恢复正确 |
| 性能 | 同机同材料，记录缓存条件、打开到首屏、删除视觉/落盘中位及范围、DOM和进程内存 |
| 大项目 | 原 80 页项目使用隔离副本；原文档与素材不作为测试写入目标 |
| 工具操作 | 点击/拖拽/反向/约束/Esc/文字焦点；重新打开后对象与坐标正确 |
| 页面导航 | 搜索旧编号与短码、远端页定位、复制短码、历史、固定/重复引用 |
| 视觉 | 实际桌面截图检查常规/较窄窗口和深色模式，确认无工具遮挡 |
| 回归 | 类型、Biome、全量单元测试及相关桌面、项目、科学对象和导出流程 |
| 交付 | 本地提交、Release/Handoff、正式程序与安装来源验证，然后集中同步 origin |

## 3. 接续工作

字体实际可用性/回退、可靠的文字和公式溢出诊断是下一批科研交付重点。大库编排的批量与拖放、独立双屏演讲、评论和完整 PPTX 往返按使用需求分别推进。综合审计保存每项来源、当前实现和优先级；本版以大项目日常编辑的完成度验收。
