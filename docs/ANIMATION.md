# HUANDENG 动画编辑

对象动画保存在 PPTD 页面的 `timeline` 中。时间线、画布预览和放映使用同一份数据，写入沿用页面保存、版本检查、撤销和命名版本。

## v0.8：按演讲点击逐步呈现

新页面默认使用「演讲步骤」。每一步决定一次点击会发生什么，播放到该步结束后停下来，等演讲者继续；关键帧时间线仍可用于更精细的动画。

1. 在画布选中图片、文字、图形或组合，打开「动画」，选择「出现」「淡入」「强调」「移动」「淡出」或「消失」，然后添加效果。也可以在对象下拉框中选择目标。多选对象时，新增效果默认在同一次点击中同时播放。
2. 「单击时」开始新的一步；「与上一项同时」在上一效果开始时播放；「上一项之后」在上一效果结束后播放。延迟按这个触发时刻计算。调整步骤顺序会移动整组效果。
3. 给步骤写清楚的讲解名称，并设置时长、延迟。移动使用相对基础位置的横向和纵向距离；强调会放大后恢复。出现和消失直接完成，不需要填写持续时间。
4. 点击「逐步预演」。作者参数暂时收起，画布展示开场状态；点击前进按步骤预演，或用横向步骤导航检查某一步完成后的画面。返回编辑会恢复原来的选中效果、展开状态和输入。
5. 「换页」可设置无转场或淡入；这是进入该页的效果，独立于页内点击步骤。系统启用减少动态效果时跳过换页淡入。

### 放映控制

- `F5` 从当前序列开头放映，`Shift+F5` 从当前页放映。再次使用这两个快捷键会重新开始相应的放映。
- 点击幻灯片空白处，或按右/下方向键、PageDown、空格、Enter，播放下一步。动画正在播放时再前进，会完成当前步；本页最后一步完成后，再前进才换页。
- 左/上方向键或 PageUp 回到上一步；在本页开场时再后退，回到上一页的完成状态。演讲中同一页的另一次出现仍从开场开始。
- `Home` / `End` 定位序列首尾；`B` 或句点切换黑屏并暂停动画；`F` 切换全屏，`Esc` 退出放映。`F1` 打开键盘帮助。
- 默认只显示简洁的步骤与换页控制。需要查看时间位置时展开「动画播放控制」；「备注与下一页」是当前窗口内的辅助面板，尚不是独立双屏演讲者视图。

动画预演和放映不改写基础排版，也不会逐帧保存。输入字段内和普通按钮上的键盘行为保留原生含义；长按前进键不会连续跳过多步。

### 步骤数据与高级时间线

点击步骤保存为 `timeline.schemaVersion: 2`，权威数据只有 `effects`。播放时纯计算为时间线，共用既有采样器；不会同时保存两份可编辑动画。每个效果使用稳定的 `targetId`，例如：

```json
{
  "schemaVersion": 2,
  "effects": [
    { "id": "reveal-figure", "targetId": "figure", "kind": "fade-in", "trigger": "click", "durationMs": 400, "delayMs": 0, "label": "展示结果图" },
    { "id": "show-arrow", "targetId": "arrow", "kind": "appear", "trigger": "after-previous", "durationMs": 0, "delayMs": 0 }
  ]
}
```

上述两项属于一次点击：结果图先淡入，随后箭头出现。`with-previous` 表示与前一效果同时开始。首项必须为 `click`；同一个对象同一属性的重叠动画会被拒绝并显示原因。每页最多 256 个效果，编译后最长 600 秒。单个渐变/移动/强调效果最长 60 秒，延迟最长 600 秒并受整页总长约束。删除对象或中间效果、筛选复制对象时，保留下来的效果维持原点击组中的播放时间与间隔；若删除组头，首保留项成为新的点击起点并保留原等待时间。

需要逐帧编辑时，点击「改用高级时间线」；已有步骤时，在对话框选择「转换为关键帧」确认。转换保存一次可撤销操作；转换后使用下节的自由时间线界面，当前不提供反向自动推断点击效果。已有 v1 文档继续使用原时间线，不会被自动转换。未来未知 schema 仍保留原数据，并明确提示当前版本不能编辑。

换页效果单独保存为 `transition`，可通过共享 `page.transition.set` 事务写入；`transition: null` 删除已支持的设置。转换动画不会删除换页设置。

## 高级自由时间线（v1）

1. 选中一个对象，点击画布下方的「动画」。选择水平位置、垂直位置、旋转、水平缩放、垂直缩放或不透明度，再点击「添加轨道」。
2. 新轨道创建起点和终点，两者初始值都来自对象的基础值。编辑器自动选中终点、把播放头移到终点，并在保存后聚焦数值字段。按提示修改终点数值，再点击播放；编辑器不会替你猜测运动距离。
3. 位置使用文档坐标，旋转使用角度，缩放和透明度在界面显示为百分比。需要中间状态时，定位播放头，再添加关键帧。
4. 点击关键帧，在属性区修改时间、数值与缓动；也可以水平拖动关键帧调整时间。一次完成的拖动保存为一次操作，Esc 取消当前拖动。
5. 拖动播放头或播放动画检查效果。预览不改变基础几何，也不按每一帧产生保存历史。点击「返回编辑」继续基础排版。
6. 添加「演讲步骤」，记录需要停下来讲解的时间和名称。放映时前进键播放至下一个步骤；播放中再按前进键会到达当前步骤终点；到最终帧后再前进才换页。后退回到上一个步骤，起点之前才回上一页。

时长、播放头、关键帧和演讲步骤的时间均显示为秒，精度为 0.001 秒。例如输入 `1.25` 秒会保存为 `1250` 毫秒，重新打开仍显示 `1.25`。小于毫秒精度的输入、空值和超范围数值会提示修正，不会静默舍入；按 Esc 可恢复原值。文档中的时间单位保持整数毫秒。

时间线普通非输入焦点下，左右方向键调整播放头 0.01 秒，Shift 调整 0.1 秒，Home/End 到起点/终点。可编辑页面的菱形关键帧获得焦点时，左右方向键改为移动该关键帧 0.01 秒，Shift 移动 0.1 秒；这会修改并保存关键帧时间。Delete/Backspace 删除当前关键帧。

菱形关键帧有焦点时，空格播放/暂停；普通按钮有焦点时，空格激活当前按钮。普通时间线焦点下按 Esc 停止预览并返回基础版式，保留草稿；输入或拖动中的 Esc 优先取消当前输入或拖动。输入框保留正常文字与数值编辑行为；F6 可切换工作区。键盘帮助在 F1 中。

## 保存、复用与版本

- 每条轨道指向稳定 `elementId`，不是当前的图层序号。轨道和关键帧也有各自的稳定 ID。
- 页面复制重新映射对象引用。旧 v1 的对象复制携带所选轨道，位置关键帧跟随复制偏移，Cue 继续使用目的页面的设置。
- v2 对象跨页复制携带筛选后的点击组，追加到目的页并保留组内等待和并发；同页复制的对象随对应原效果同时播放。移动的相对距离不会重复叠加复制偏移。两个非空 v1/v2 模式之间的动画粘贴会被拒绝，需先明确转换。
- 删除对象会在同一事务中移除它的相应动画。撤销恢复对象及其轨道或步骤效果，命名版本保留当时的动画数据。
- 同一 `pageId` 在演讲的多处出现时，共享动画内容；每个 `occurrenceId` 的放映从起点重新开始。固定版本引用播放所记录版本的时间线。
- 组合轨道作用于成员。成员可以保留自己的轨道，父级动画增量叠加到成员采样结果。取消带有自身动画的组合前，界面要求先处理该组合轨道，避免悄悄移除运动效果。
- 保存发生冲突时保留草稿，不以旧 revision 覆盖新页面。先复制动画草稿，再决定还原到最新内容或重新应用。

## 数据和 Agent

以下是一个从横坐标 80 移到 400，并在 1 秒处停顿讲解的时间线；实际 `targetId` 必须对应本页对象。

```json
{
  "schemaVersion": 1,
  "durationMs": 2000,
  "tracks": [{
    "id": "figure-x",
    "targetId": "figure",
    "property": "x",
    "keyframes": [
      { "id": "start", "timeMs": 0, "value": 80, "easing": "ease-in-out" },
      { "id": "end", "timeMs": 2000, "value": 400, "easing": "linear" }
    ]
  }],
  "cues": [{ "id": "explain", "timeMs": 1000, "label": "解释比较关系" }]
}
```

通过共享事务写入：`{ "op": "page.timeline.set", "pageId": "真实页面 UUID", "timeline": {...} }`。`timeline: null` 删除这一页的受支持时间线。GUI、CLI apply 与 `huandeng_apply` 都使用页面 expected revision 和 requestId；先读取 Story briefing、对象和当前 revision，再构造事务。不要直接替换整份 `.page` 或建立另一套 JSON 保存源。

easing 作用于本关键帧到下一帧：`linear` 匀速，`ease-in-out` 平滑，`hold` 保持到下一帧再跳变。轨道范围之外保持端点值；旋转可保留多圈。时间为整数毫秒，同轨时间严格递增，单页最长 600000ms。模型拒绝孤儿目标、非有限数值、重复对象/属性轨道及无效组合关系。

旧的未知 `animations` 字段继续原样保留。未来 timeline schema 的页面仍可静态查看，但当前时间线编辑器不会把未知数据当成空白并覆盖。

## 当前输出范围

PPTD 编辑器和放映支持点击步骤、关键帧与页面淡入转场。PNG/PDF/PPTX 当前使用基础版式；三种导出报告均包含 `renderState: 'base'`，存在时间线时记录 `TIMELINE_STATIC_EXPORT`，说明动画留在 PPTD。静态文件不包含原生 PowerPoint 动画；设置了淡化等非「无转场」效果时报告 `TRANSITION_NOT_EXPORTED`。在编辑器预览和放映中，GIF 等动态图片仍由浏览器播放，尚未与对象播放头统一逐帧同步；视频导出对这些自主动画采用下节的明确拒绝规则。

v0.7 已增加确定时间的 MP4 视频导出，设置和边界见下节。可编辑运动路径/曲线、自动打关键帧、音视频轨与波形和 PowerPoint 原生 timing tree 仍属于后续独立工作。早期方案比较见 [动画审计](AUDIT-V06-ANIMATION.md)，点击放映交付设计见 [SPEC-V08](SPEC-V08.md)，视频交付边界见 [SPEC-V07](SPEC-V07.md)。

## v0.7：导出动画视频

顶部“导出”选择 **动画视频 · MP4**。范围可以是当前页，也可以是当前 Main/Presentation 的完整顺序；重复使用的页面保持每次出现，固定版本使用所固定的内容。

默认 720p/30fps，也可选择 1080p、24fps。无时间线页面默认停留 3 秒；有时间线页面播放到结尾后停留 1 秒。“每步额外停留”把演讲时等点击的 cue 转换为固定时长，默认 0 秒；开始前显示预计总时长。最长 10 分钟、最多 18000 帧。视频为 H.264/yuv420p，无音轨和页面转场；点击步骤使用同一纯计算时间线转为定时播放，页面转场未导出时报告 `TRANSITION_NOT_EXPORTED`。

开始导出会先提交页面并要求处理尚未保存的辅助草稿，然后冻结文稿与素材。导出期间可以关闭弹层继续编辑，再打开查看进度或取消；后续编辑不会改变正在导出的版本。成功结果保存到 Exports（只读会话保存在本机输出目录），显示文件位置、下载和导出报告。任务下载链接默认保留 15 分钟，成品文件不会因链接过期删除。

需要可用且包含 libx264 的 FFmpeg。编辑器依次检查 HUANDENG_FFMPEG 指定路径、应用旁的 tools/ffmpeg.exe（Windows）或 tools/ffmpeg、PATH。更改配置后重新打开编辑器。未找到时给出说明；静态导出和普通素材编辑继续可用。安装包不自动下载 FFmpeg。

视频使用统一时间采样。自主播放的 GIF/APNG/动态 WebP、含自主动画或脚本的 SVG 暂时需要换为静态素材；这是开始前可修复的明确错误，不会悄悄导出不一致的实时播放。PPTD 对象的关键帧动画不受此限制。

CLI 的 video 命令启动作业，export-status 与 export-cancel 查询/取消；--help 列出选页、分辨率、帧率与停留参数。MCP 的同一 export 工具接受 MP4，并提供独立的状态/取消工具，详见 [Plugin 使用说明](../plugins/huandeng/README.md)。真实客户端安装与协议能力分别验证。
