# Drug Design

Open `deck.pptd` in HUANDENG. The project contains ten editable Main Slides and three contiguous Sections.

Select **Drug Design · Full overview** for the full Presentation or **Drug Design · Five-slide briefing** for a shorter selection. Both reference the same canonical pages.

Each slide has speaker notes and primary-source citations. `SOURCES.md` contains the bibliography. Text, tables and process diagrams are native editable objects. The diagrams are conceptual rather than molecular structures or experimental results.

To generate a fresh copy from the repository, run `node scripts/create-drug-design-v010.mjs <new-directory>`. The generator refuses to overwrite an existing deck unless `--replace` is supplied.
