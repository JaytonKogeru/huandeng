# Public HUANDENG evidence projects

Open either Public-Evidence-EN/deck.pptd or Public-Demo-ZH/deck.pptd in HUANDENG Editor.
Each project has six active pages and a three-page short presentation referencing the same source pages.
The authored page files, identity metadata, imported originals and named checkpoints are copied byte for byte.

English: the changed page has Before copy edit and Copy tightened checkpoints.
Chinese: the changed page has corresponding Chinese checkpoint labels.
Use History / Saved versions to compare these named versions. The current page contains the shorter copy.
Operation and activity history belong to the local writer state and are not part of this portable copy.
The proofs folders retain the recorded two-object edit, before/after data and identity-move/undo receipts.
These are public worked examples, not measured customer outcomes or performance benchmarks.

No fonts are bundled. The examples use Arial and Microsoft YaHei and the viewer resolves available fonts.
The manifest records the preserved source files and their hashes. SHA256SUMS.txt covers the deliverable.
The included MIT license preserves the HUANDENG project notice.
