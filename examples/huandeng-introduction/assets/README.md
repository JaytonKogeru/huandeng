# HUANDENG UI assets 0.18.0

120 original PNG captures, organized by review status and UI language. PNG bytes and SHA-256 hashes are unchanged.

## Selection

- recommended: final task choices reviewed at useful display sizes.
- reference: additional captures; individual review status is recorded.
- diagnostic: mixed-language examples, empty history, or an earlier dialog width. These explain audit findings and are not final presentation images.

## Provenance

All images show public product examples in the actual HUANDENG Editor. No customer project or performance measurement is implied.
Public-Evidence-EN and Public-Demo-ZH are logical source names. Their portable companion projects are distributed separately in evidence-projects.
Complete windows were captured at native DPR2; focused tasks at native DPR4. No bitmap was enlarged to create resolution.
The two-object edit, named versions, operation review and identity reorder are actual product states.
Operation review uses the current project image bytes, as stated by its UI. These worked edits change text only.
