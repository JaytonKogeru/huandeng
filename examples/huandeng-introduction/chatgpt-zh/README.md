- Main：22 页，包含 3 张仅含章节标题的过渡页。
- 完整介绍：引用全部 22 页。
- 简短介绍：引用其中 8 页，适合快速说明。
- 每页附讲者备注与 Story，并保存“v0.18 项目介绍 · 视觉审读版”命名版本。
- 背景统一为白色，正文使用常规字重；原始截图按实际中文界面和中文内容采集。

ASSETS.json 记录截图来源、语言、像素尺寸、SHA-256 和每处使用的裁剪。较早导入的素材保留，以免破坏既有修改记录。Project 的命名版本随目录移动；应用的临时 Undo/操作日志不作为便携历史。

PDF 与可编辑 PowerPoint 在 v0.18.0 Release 中单独提供。PPTX/PDF 保留静态页面；现场点击动画属于 Editor 播放。
