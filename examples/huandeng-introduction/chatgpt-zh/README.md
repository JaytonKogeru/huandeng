# HUANDENG：在 Editor 里完成一次实际修改

在 Editor 0.19 中打开 [deck.pptd](deck.pptd)，并保留整个项目文件夹。

这份 24 页中文教程由三个并行分段助手各制作 8 页，主会话负责共享编排、整合与逐页视觉复核。每页水印为 **Chinese · ChatGPT 6 Astra + Subagents**。它与英文版独立组织，不要求中英文逐页对应。

## 从一页开始，完成一次交付

| Main 页面 | 可以跟着完成的操作 |
| --- | --- |
| 1–3 | 理解持续修改的需要，以及 Editor、助手与项目的关系。 |
| 4–8 | 打开项目、加页、定位对象、写 Story、放素材、检查并保存。 |
| 9–16 | 改属性、比较前后、用图层和裁切、查保存回执、写备注、命名版本和重排页面。 |
| 17–21 | 为演讲选页、写单次引用备注、选择跟随或固定版本、预演并核对导出范围。 |
| 22–24 | 连接真实客户端、按页面与保存结果协作、完成自己的第一次修改。 |

大幅操作截图来自实际 Editor。前后比较使用统一比例、清楚的标签与视觉引导；箭头、文字与说明图形仍可编辑。历史科学示例和原始材料继续保留在来源与版本中，但不再承担本教程的主线。

[speaker-notes.md](speaker-notes.md) 从当前 Main 与实际解析后的短版 Notes 提取。继续修改时，请编辑项目中的对应页面或演讲引用备注。
