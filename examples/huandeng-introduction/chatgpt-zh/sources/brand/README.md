# Shared introduction identity assets

A small set for the four HUANDENG introduction projects: the existing HUANDENG mark, its user-supplied source, four client marks, and three direct code-source identifiers. These files retain the exact pixels used by the original introduction or its existing repository source. No image was redrawn, recolored, cropped or resampled for this collection.

Read [manifest.json](manifest.json) for relative file paths, original pixel dimensions, source URLs, upstream processing and SHA-256 hashes. [SHA256SUMS.txt](SHA256SUMS.txt) verifies this collection. All manifest paths resolve from this directory.

| File | Use |
| --- | --- |
| huandeng.png | Default HUANDENG mark, identical to the original reference deck's cover and footer asset |
| huandeng-user-original.png | Unmodified user-supplied original, retained as source provenance |
| codex.png | Official OpenAI extension mark, paired with the name Codex |
| claude-code.png | Official Claude mark, paired with the name Claude Code |
| deepseek.png | DeepSeek organization mark; identify Harness separately in text |
| chatgpt.png | Official ChatGPT mark |
| open-slide.png | OpenSlide, the editor code foundation |
| github-repository.png | Repository identifier beside OpenPPTD; this is a GitHub mark, not an OpenPPTD logo |
| pptxgenjs.png | PptxGenJS, the PPTX export library |

Use native text for product names and contribution descriptions. Preserve original colors and proportions. Keep each mark legible and leave clear space; do not use client logos as generic bullets. The assets identify named products and actual source relationships. Third-party marks retain their own ownership and source terms; repository MIT licensing does not relicense them.

The [original introduction PDF](../reference/original-demo.pdf) is a historical design reference. The current task permits meaningful diagrams, backgrounds, icons and charts; a sparse white page is not a visual acceptance criterion.
