# HUANDENG 工作流介绍

## 目的与听众
介绍人与 Agent 怎样持续编辑、复用并交付同一份演示作品。听众是演示作者与开源贡献者。

## 页面约定
- 主稿共22页。第3、8、17页是纯章节标题页，只有一个标题对象。
- 普通页与章节页统一白底 #FFFFFF，正文 #202423，辅助文字 #616A67。
- 960×540 画布。中文普通标题28，正文17–20，章节标题34；正文使用常规字重。
- Microsoft YaHei 为中文正文与标题字体。品牌字样可以单独设置字号。
- 一个页面解释一个明确问题，长解释与来源放在讲者备注。
- 使用真实 Editor 截图，保留原始像素、正确语言及来源。功能细节使用可读的任务区域。
- 不添加装饰箭头、圆圈编号、渐变、占位图表或重复卡片。

## 编辑与交付
- 通过共享写入服务预览并保存修改，不直接覆盖页面文件。
- 保留页面身份、Story 与完整及简短 Presentation 的引用。
- 重大修改先制作内容页与章节页框架，确认实际渲染后再展开。
- 逐页查看渲染与整套缩略图，检查文字边界、截图清晰度与重复节奏。
- PDF/PPTX 是静态交付，现场点击效果在 Editor 中使用。
- 素材来源见 assets-provenance.json，许可证与致谢见项目仓库。
